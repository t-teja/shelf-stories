## Features

- Showcase slideshow of the full owned collection
- Add / edit by name, SKU, barcode, or model — camera + gallery uploads
- Purchase fields: price, quantity, purchased from, date, product link
- Rooms: Showcase, Collection, Garage, Brick Yard, Vault, Hangar, Paddock, Wishlist, Gallery Wall
- Collapsible sidebar, search, filters, sort, duplicate warnings
- Seeded with Ferrari Daytona SP3 (`42143`) and F1 Speed Champions `77242`–`77251`
